MODE 1: Trigger Logic & Idempotency

COALESCE handles out-of-order events

BEFORE INSERT Trigger:

INSERT INTO workflow_instances (
  id, name, status, start,
  end, input, output
) VALUES (...)
ON CONFLICT (id) DO UPDATE SET
  name = COALESCE(
    workflow_instances.name,
    EXCLUDED.name
  ),
  status = CASE
    WHEN EXCLUDED.status IN
      ('COMPLETED','FAULTED')
    THEN EXCLUDED.status
    ELSE workflow_instances.status
  END,
  start = COALESCE(
    workflow_instances.start,
    EXCLUDED.start
  ),
  end = COALESCE(
    EXCLUDED.end,
    workflow_instances.end
  ),
  input = COALESCE(
    workflow_instances.input,
    EXCLUDED.input
  ),
  output = COALESCE(
    EXCLUDED.output,
    workflow_instances.output
  );

Out-of-Order Events:

Idempotency Rules:

  • Immutable (first wins): name, version, start, input
  • Terminal (last non-null): end, output, error
  • Status: COMPLETED/FAULTED > RUNNING > CREATED
