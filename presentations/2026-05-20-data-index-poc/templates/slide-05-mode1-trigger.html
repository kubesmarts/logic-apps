MODE 1: Trigger Logic & Idempotency

COALESCE handles out-of-order events

BEFORE INSERT Trigger Code:

INSERT INTO workflow_instances (
  id,
  name,
  status,
  start,
  end,
  input,
  output
) VALUES (
  new_id,
  new_name,
  new_status,
  new_start,
  new_end,
  new_input,
  new_output
)
ON CONFLICT (id) DO UPDATE SET
  name = COALESCE(
    workflow_instances.name,
    EXCLUDED.name
  ),
  status = CASE
    WHEN EXCLUDED.status IN
      ('COMPLETED','FAULTED')
    THEN EXCLUDED.status
    ELSE workflow_instances.status
  END,
  start = COALESCE(
    workflow_instances.start,
    EXCLUDED.start
  ),
  end = COALESCE(
    EXCLUDED.end,
    workflow_instances.end
  ),
  input = COALESCE(
    workflow_instances.input,
    EXCLUDED.input
  ),
  output = COALESCE(
    EXCLUDED.output,
    workflow_instances.output
  );

Out-of-Order Event Handling:

Idempotency Rules:

  • Immutable fields (first value wins): name, version, start, input
  • Terminal fields (last non-null wins): end, output, error
  • Status: Terminal state precedence (COMPLETED/FAULTED > RUNNING > CREATED)
