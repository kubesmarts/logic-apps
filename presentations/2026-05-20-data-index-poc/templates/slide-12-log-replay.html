Capacity & Tuning: Log Replay

Can we replay old logs from /var/log/kubernetes?

Replay Mechanism:

  • Retention: /var/log/containers/ (7-30d)
  • Restart: Re-reads if position DB lost
  • Manual: Delete position DB, restart
  • Selective: kubectl cp + re-inject

Idempotency:

  • MODE 1: UPSERT + COALESCE
  • MODE 2: Transform aggregates by ID
  • No corruption: Out-of-order OK
  • Safe replay: No side effects

✅ Answer: Yes, idempotent design allows safe replay.
