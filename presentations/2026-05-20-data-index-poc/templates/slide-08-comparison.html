MODE 1 vs MODE 2: Feature Comparison

Feature MODE 1 (PostgreSQL) MODE 2 (Elasticsearch)
Normalization Latency < 1ms (triggers) ~1s (transforms)
Consistency Model Strong (ACID) Eventual (AP)
Scaling Strategy Vertical + read replicas Horizontal (sharding)
Capacity < 50K workflows/day > 50K workflows/day
Full-Text Search ❌ (tsvector possible) ✅ Native
Complex Aggregations ⚠️ Limited ✅ Advanced
Multi-Tenancy Row-level security Index-per-tenant
Operational Complexity Low (single DB) High (ES cluster)
GraphQL API ✅ Identical (SmallRye GraphQL)
