MODE 2: Transform Logic & Idempotency

Painless script handles field-level COALESCE

Transform (Painless):

{
  "source": {
    "index": "workflow-events",
    "query": {
      "bool": { "should": [
        { "range": { "@timestamp":
            { "gte": "now-1h" } } },
        { "bool": { "must_not": {
          "terms": { "status":
            ["COMPLETED","FAULTED"] } } } }
      ]}
    }
  },
  "dest": { "index": "workflow-instances" },
  "pivot": {
    "group_by": { "id": { "terms":
        { "field": "id" } } },
    "aggregations": {
      "name": { "scripted_metric": {
        "reduce_script": "all[0]"
      }},
      "status": { "scripted_metric": {
        "reduce_script":
          "all.contains('COMPLETED') ?
           'COMPLETED' : all[all.size()-1]"
      }},
      "start": { "scripted_metric": {
        "reduce_script": "all[0]"
      }},
      "end": { "scripted_metric": {
        "reduce_script":
          "all.findLast{it != null}"
      }}
    }
  },
  "frequency": "1s"
}

Smart Filtering:

  • Events from last 1h
  • OR active workflows
  • Skip old completed

Idempotency Rules:

  • Immutable: First wins
  • Terminal: Last non-null
  • Status: Terminal > active
