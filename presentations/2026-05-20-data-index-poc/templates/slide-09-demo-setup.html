Demo Environment (KIND Cluster)

Production-like deployment on local Kubernetes

MODE 1: PostgreSQL

Components:

  • PostgreSQL 15
  • Data Index - GraphQL
  • FluentBit - Logs
  • Workflow App - Events

Deploy:

cd data-index/scripts/kind
./setup-cluster.sh
MODE=postgresql ./install-dependencies.sh
./deploy-data-index.sh postgresql
cd ../fluentbit/mode1-postgresql-triggers
./generate-configmap.sh
kubectl apply -f kubernetes/
cd ../../kind
./deploy-workflow-app.sh
