Demo Environment (KIND Cluster)

Production-like deployment on local Kubernetes

MODE 1: PostgreSQL Demo

Components Running:

  • PostgreSQL 15 - Database backend
  • Data Index Service - GraphQL API
  • FluentBit DaemonSet - Log collection
  • Test Workflow App - Generates events

Deployment Scripts:

cd data-index/scripts/kind

# Setup cluster
./setup-cluster.sh

# Install PostgreSQL
MODE=postgresql ./install-dependencies.sh

# Deploy Data Index
./deploy-data-index.sh postgresql

# Deploy FluentBit (MODE 1)
cd ../fluentbit/mode1-postgresql-triggers
./generate-configmap.sh
kubectl apply -f kubernetes/

# Deploy test app
cd ../../kind
./deploy-workflow-app.sh
