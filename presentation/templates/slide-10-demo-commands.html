Live Demo Commands

Interactive demonstration of Data Index in action

1. Verify Components Running

# Check Data Index service
kubectl get pods -n data-index

# Check FluentBit DaemonSet
kubectl get pods -n logging

# Check workflow app
kubectl get pods -n default

2. Trigger Workflow Execution

# Execute test workflow (generates events)
curl -X POST http://localhost:30081/greeting \
  -H "Content-Type: application/json" \
  -d '{"name": "Data Index Demo"}'

# Response: {"id": "workflow-abc123", "message": "Workflow started"}

3. Watch Events Flow (FluentBit Logs)

# Tail FluentBit logs to see event processing
kubectl logs -n logging -l app=workflows-fluent-bit-mode1 -f

# Or for MODE 2:
kubectl logs -n logging -l app=workflows-fluent-bit-mode2 -f

4. Query via GraphQL

# Get all workflow instances
curl -X POST http://localhost:30080/graphql \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ workflowInstances { id name status startDate endDate } }"
  }'

# Filter by status
curl -X POST http://localhost:30080/graphql \
  -H "Content-Type: application/json" \
  -d '{
    "query": "{ workflowInstances(where: {status: {equal: COMPLETED}}) {
      id name status startDate endDate taskExecutions { id name status }
    }}"
  }'

5. Verify Data Normalization

# MODE 1: Check PostgreSQL tables
kubectl exec -it -n data-index postgresql-0 -- psql -U postgres -d dataindex \
  -c "SELECT id, name, status, start FROM workflow_instances;"

# MODE 2: Check Elasticsearch indices
kubectl port-forward -n data-index svc/elasticsearch 9200:9200
curl http://localhost:9200/workflow-instances/_search?pretty
