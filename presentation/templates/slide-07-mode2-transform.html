MODE 2: Transform Logic & Idempotency

Painless script handles field-level COALESCE

Elasticsearch Transform (Painless):

{
  "source": {
    "index": "workflow-events",
    "query": {
      "bool": {
        "should": [
          {
            "range": {
              "@timestamp": {
                "gte": "now-1h"
              }
            }
          },
          {
            "bool": {
              "must_not": {
                "terms": {
                  "status": [
                    "COMPLETED",
                    "FAULTED",
                    "CANCELLED"
                  ]
                }
              }
            }
          }
        ]
      }
    }
  },
  "dest": {
    "index": "workflow-instances"
  },
  "pivot": {
    "group_by": {
      "id": {
        "terms": { "field": "id" }
      }
    },
    "aggregations": {
      "name": {
        "scripted_metric": {
          "init_script": "state.values = []",
          "map_script": """
            if (doc['name'].size() > 0) {
              state.values.add(doc['name'].value)
            }
          """,
          "combine_script": "return state.values",
          "reduce_script": """
            def all = [];
            for (s in states) {
              all.addAll(s);
            }
            return all.size() > 0 ?
              all[0] : null;
          """
        }
      },
      "status": {
        "scripted_metric": {
          "reduce_script": """
            // Terminal state wins
            if (all.contains('COMPLETED'))
              return 'COMPLETED';
            if (all.contains('FAULTED'))
              return 'FAULTED';
            return all[all.size()-1];
          """
        }
      },
      "start": {
        "scripted_metric": {
          "reduce_script": """
            // First value wins (immutable)
            return all[0];
          """
        }
      },
      "end": {
        "scripted_metric": {
          "reduce_script": """
            // Last non-null wins (terminal)
            for (int i=all.size()-1; i>=0; i--) {
              if (all[i] != null) return all[i];
            }
            return null;
          """
        }
      }
    }
  },
  "frequency": "1s",
  "sync": {
    "time": {
      "field": "@timestamp",
      "delay": "60s"
    }
  }
}

Smart Filtering:

Query optimization:

  • Process events from last 1 hour
  • OR workflows still active (not in terminal state)
  • Skip old completed workflows (won't change)

Idempotency Rules:

  • Immutable fields: First value wins (name, version, start, input)
  • Terminal fields: Last non-null wins (end, output, error)
  • Status: Terminal state precedence (COMPLETED/FAULTED > RUNNING > CREATED)

⚡ Performance: Constant processing time regardless of total workflow count (smart filtering)
