= Ports and endpoints
:page-aliases:

== Metrics

Besides the standard JVM, HTTP and connection-pool metrics, Data Index publishes:

=== Raw event polling (`-postgresql`)

[cols="2,3"]
|===
|Metric |Description

|`+data_index_jdbc_batch_events_processed_total{type}+`
|Raw rows normalized. `type` is `workflow` or `task`.

|`+data_index_jdbc_batch_events_dlq_total{type}+`
|Raw rows moved to `workflow_events_dlq` / `task_events_dlq`.

|`+data_index_jdbc_batch_dlq_write_failed_total{type}+`
|Rows that could not be written to the DLQ table. Should stay at 0.
|===

=== Elasticsearch transforms (`-elasticsearch`)

All gauges have a `transform` label: `workflow-instances-transform` or `task-executions-transform`.

[cols="2,3"]
|===
|Metric |Description

|`data_index_transform_state`
|`1` started, `0` stopped, `2` failed, `-1` unknown.

|`data_index_transform_lag`
|Documents waiting to be processed.

|`data_index_transform_documents_processed`
|Documents read since the transform started.

|`data_index_transform_documents_indexed`
|Documents written to the normalized index.

|`data_index_transform_last_checkpoint`
|Last completed checkpoint.
|===

Alert when `data_index_transform_state != 1` or when `data_index_transform_lag` keeps growing.
